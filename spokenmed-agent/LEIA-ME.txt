O QUE É
───────
Programinha que roda no seu PC, em loop. A cada 30 minutos faz login no
Fiorilli com as credenciais do arquivo "agent.cfg", abre o Ambulatório, pega
o _S_ID atualizado e manda direto pro Worker Cloudflare. Resultado: você NUNCA
MAIS precisa copiar o curl do DevTools.

Não precisa instalar Python nem nada. O Python já vem dentro da pasta
"runtime/".


PRIMEIRO USO (3 passos)
───────────────────────
1) Abra o arquivo "agent.cfg" no Bloco de Notas, cole a sua API KEY do Worker
   e confira FIORILLI_USERNAME / FIORILLI_PASSWORD. Salve.

2) Dê duplo-clique em "Iniciar Agente.bat" pra testar.
   Você verá uma janela preta com logs tipo:
       → GET /sis/
          _S_ID inicial = O4Rl…41E3
       → POST cinfo (seq=1)
       → POST login click (user=admin)
       ✓ login OK — sessão pronta
       ✓ Worker atualizado: { ok: true, ... }
   Pode fechar a janela quando confirmar que tá funcionando.

3) Dê duplo-clique em "INSTALAR Inicio Automatico.bat". Pronto — o agente
   vai rodar silenciosamente toda vez que você logar no Windows.


DIA A DIA
─────────
• Nada. Sério. Ele cuida sozinho.
• Se quiser ver se tá rodando: abra "agent.log" (criado automaticamente
  ao lado deste README).
• Se mudar a senha do Fiorilli: edite FIORILLI_USERNAME/FIORILLI_PASSWORD no
  "agent.cfg" e reinicie.
• Se mudar a API key do Worker: edite "agent.cfg" e reinicie.


REINICIAR / PARAR
─────────────────
• Pra parar o agente silencioso: abra o Gerenciador de Tarefas (Ctrl+Shift+Esc),
  procure por "pythonw.exe" e finalize. (Próximo login do Windows ele volta.)
• Pra desativar de vez o início automático: dê duplo-clique em
  "DESINSTALAR Inicio Automatico.bat".


SOLUÇÃO DE PROBLEMAS
────────────────────
"login NÃO autenticado — credencial inválida"
  → Usuário/senha do Fiorilli estão errados. Edite agent.cfg.

"POST /session/update — status=401"
  → WORKER_API_KEY errada em agent.cfg.

"GET inicial falhou: status=403"
  → O IP da sua rede pode estar bloqueado pelo Cloudflare do Fiorilli.
    Teste abrir https://saudeteresopolis.oppcloud.com.br/sis/ no navegador
    da mesma máquina — se abrir, o agente também consegue.

Agent não inicia / abre e fecha
  → Rode o "Iniciar Agente.bat" (modo visível) pra ver a mensagem de erro
    completa antes de fechar.


COMO ELE FUNCIONA POR DENTRO
─────────────────────────────
1. GET https://saudeteresopolis.oppcloud.com.br/sis/  → _S_ID inicial
2. POST handshake (cinfo + activate + show + login click)
3. POST polls _dummy_ até validar credenciais
4. POST itemclick Ambulatório → GET /ambulatorio/  (SSO)
5. POST inicialização ambulatório (cinfo + afterrender + resize + dummies)
6. POST escolha de unidade (popup O58D)
   — usa FIORILLI_UNIDADE_INDEX do agent.cfg (default 4)
7. POST navegação até Pacientes → Prontuário → CadSUS
   — deixa os componentes O117A/O11B2 registrados no _S_ID
8. POST {WORKER_URL}/session/update  (manda _S_ID + cookies pro Worker)
9. dorme 30 min, repete

Tudo HTTP puro. Sem browser, sem Selenium, sem Chromium.

CONFIG DE UNIDADE
─────────────────
Se sua conta tem mais de uma unidade no popup pós-login, o agente seleciona
pelo índice (0 = primeira). Edite FIORILLI_UNIDADE_INDEX no agent.cfg.



SUPORTE
───────
Se quebrar, manda o conteúdo do "agent.log" que dá pra debugar fácil.
